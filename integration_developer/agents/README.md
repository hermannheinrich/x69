# Integration-Developer-Agents

Dieser Ordner ist für die Integration-Suite-spezifischen Agents vorgesehen.

Die detaillierten Agents werden in einem separaten Schritt definiert. Bis
dahin gelten die Rollen- und Zugriffsgrenzen aus
`governance/integration_developer_rules.md`.

Keine Datei in diesem Ordner darf PATs, Passwörter, Service Keys, Cookies,
Zertifikate oder persönliche absolute Pfade enthalten.
